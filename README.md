The main essence of the project is the study of dimensionality reduction methods, working with sparse features, analyzing images and video using SVD, and comparing models on compressed features. For the Book Recommendation Dataset, a sparse user–book interaction matrix was built, a linear model and Random Forest were trained to predict user age with optimal parameter selection, PCA and UMAP were applied for dimensionality reduction, after which the models were trained on the compressed features and the training time and quality before and after compression were compared. For visualization: MNIST was loaded, transformation to 2D was performed using PCA, SVD, Randomized-SVD, t-SNE, UMAP, and LLE, metrics were proposed, and the quality of digit class separation was compared. For image compression: SVD decomposition was performed, low-rank approximations were built for up to 10 different ranks, and the singular value spectrum and explained variance distribution were analyzed. For background detection: SVD decomposition of a frame was performed, the first frame was reconstructed using low-rank approximation, and the rank was selected to obtain the background. As part of the submission, one of the models from the Visualizations part was saved, and code was prepared for loading, applying, and reproducing the compression of a handwritten digit.
